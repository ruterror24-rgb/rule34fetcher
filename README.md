# Rule34 Fetcher

Небольшое Windows-приложение с графическим окном для поиска по тегам и скачивания оригиналов изображений и видео с rule34.xxx.

## Подготовка

1. Установите Rust и Visual Studio Build Tools с компонентом **Разработка классических приложений на C++**.
2. Скопируйте `r34.env.example` в `r34.env`.
3. В `r34.env` укажите свой `user_id` и настоящий `api_key` из настроек аккаунта.

```env
user_id=ВАШ_ID
api_key=ВАШ_КЛЮЧ
```

## Запуск

Из папки проекта выполните `cargo run`. Откроется окно приложения. Также можно собрать release-версию командой `cargo build --release`, затем запустить `target\release\rule34-fetcher.exe` двойным щелчком. Файл `r34.env` должен оставаться в корне проекта.

В окне задайте включаемые теги, исключаемые теги, максимальное число постов и диапазон страниц (страницы нумеруются с 1, границы включаются). При вводе двух и более символов приложение показывает выпадающие подсказки тегов сайта с количеством постов в скобках; клик по подсказке вставляет тег. После добавления тега программа автоматически проверяет запрос и выставляет конечную страницу по числу совпадений (до 200 страниц); диапазон можно изменить вручную. Нажмите **Проверить теги**, чтобы увидеть число постов с каждым тегом и итоговое количество результатов после применения включений и исключений. Поиск доступен, если все указанные теги найдены. Во время загрузки кнопка **Остановить загрузку** прерывает задачу и удаляет незавершённые `.part`-файлы. Исключения добавляются к поиску с префиксом `-`. На одной странице запрашивается до 100 постов. Загрузки помещаются в `downloads`.
